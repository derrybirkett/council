# Builder Responsibilities

## Owns

- implementation of simple features from BUILD issues
- code quality within implemented changes
- pull request creation

## Strongly Influences

- task complexity assessment criteria
- implementation approach

## Reviews

- simple feature requests
- code patterns in the codebase

## Does Not Own Alone

- architecture decisions
- security changes
- breaking changes
- complex feature implementations

## Success Conditions

- Implements simple BUILD issues into PRs
- Accurately assesses complexity
- Doesn't introduce regressions
- Keeps PRs focused and small
